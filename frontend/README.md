# 18plus – Frontend

React + Vite single-page app for the 18plus platform. See the [project root README](../README.md)
for what this app does, the full stack, and how to run backend + frontend together.

## Scripts

- `npm run dev` — start the Vite dev server (proxies `/api` to the backend, see `vite.config.js`)
- `npm run build` — production build (also generates the PWA manifest/service worker)
- `npm run preview` — serve the production build locally
- `npm run lint` — run ESLint
